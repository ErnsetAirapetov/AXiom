# Документация AXiom

Карта того, что где лежит и когда это читать.

| Файл | Что внутри | Когда читать |
|---|---|---|
| `../README.md` | Назначение, принципы, чем проект не является — утверждено владельцем | Первым делом, всегда |
| `../CLAUDE.md` | Предметный слой для агентов: стек, структура, соглашения домена | Перед любой задачей в репозитории |
| `product.md` | Проблема, цели, как продукт работает, флоу пользователя | Перед работой над продуктовой логикой |
| `architecture.md` | Логические части системы и связи между ними | Перед архитектурными решениями |
| `pipelines.md` | Как система работает по шагам: пайплайн пользователя, пайплайны наполнения, уровни защиты качества ответа | Перед работой над логикой запроса или наполнения базы |
| `retrieval-design.md` | Схема поиска и её обоснование: отвергнутые альтернативы, векторный индекс, осмысленная векторизация, антипаттерны | Перед любой работой над поиском |
| `stack.md` | Технологический стек MVP, модель и стоимость, путь масштабирования от отдела до нескольких компаний | Перед выбором или заменой компонента |
| `research/competitors.md` | Конкуренты и смежные решения | При разговоре о позиционировании |
| `roadmap.md` | Вехи и эпики движения к цели | При планировании и груминге |
| `domain.md` | Глоссарий терминов проекта — обязателен к соблюдению | Перед тем как ввести новый термин или написать промпт/код на предметную тему |
| `decisions.md` | Журнал принятых решений с причинами и отвергнутыми альтернативами | Перед тем как оспорить или повторить решение |
